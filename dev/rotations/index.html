Rotations

The two bases respond very differently to a pure rotation $R$ — this is the cleanest way to tell them apart.

Set up a carrier and a rotation about $\hat y$:

β  = 0.6
p0 = FourVector(0.4, -0.2, 0.3; M = 0.4)
p1 = p0 |> Ry(β)             # rotated momentum
U  = Urot([0, 1, 0], β)      # matching SU(2)
c0 = normalize(ComplexF64[0.6, 0.8])

Canonical: the spin follows, $\text{coeffs}\to D(R)\,\text{coeffs}$

The canonical boost $u_C(p)=R\,B_z\,R^{-1}$ is covariant ($u_C(Rp)=R\,u_C(p)\,R^{-1}$), so the Wigner rotation collapses to $w=R$ itself. The coefficients transform by $D^s(R)$ — independent of the momentum:

sc = evolve(spin_state(Canonical(), p0, c0), U, p1)
sc.coeffs ≈ SpinStates._wignerD(1, U) * c0
true

wigner_rotation confirms the residual is exactly $U$:

wigner_rotation(Canonical(), p0, p1, U) ≈ U
true

This is why canonical states are the natural home for ordinary angular-momentum algebra: a rotation acts on the spin index and nothing else.

Helicity: helicity is conserved (diagonal Wigner rotation)

For a helicity state the little group of a massive particle under rotations is a rotation about the momentum, $R_z(\gamma)$. The Wigner rotation is therefore diagonal — each helicity component only picks up a phase, magnitudes are frozen:

wh = wigner_rotation(Helicity(), p0, p1, U)
round.(wh; digits = 4)
2×2 Matrix{ComplexF64}:
 0.9919+0.1274im     0.0+0.0im
   -0.0+0.0im     0.9919-0.1274im
sh = evolve(spin_state(Helicity(), p0, c0), U, p1)
abs.(sh.coeffs) ≈ abs.(c0)      # |amplitudes| unchanged: helicity is conserved
true

So under rotations: canonical mixes (by $D(R)$), helicity only rephases. Both preserve the norm, and both agree with the rigid rotation of $\langle S\rangle$ from the previous tutorial.
